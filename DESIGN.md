# Smriti Sathi — Design System Specification

## Color Palette (from Reference System)

| Token | Hex | Usage |
|---|---|---|
| **Primary** | `#162436` | Brand dark navy, primary buttons, headers, active chips |
| **Secondary** | `#9E2224` | Primary CTA red (Continue, Mark as Taken, Listen) |
| **Tertiary** | `#312006` | Deep warm accent brown |
| **Neutral** | `#777778` | Subtitle text, muted labels |
| **Canvas** | `#FBF8F2` | Warm cream page background |
| **Card** | `#FFFFFF` | White rounded cards |
| **Success** | `#1B6A45` | Medication taken, adherence, correct answer |
| **Alert/Tab Active** | `#FF5F56` | Active navigation pill, skip button |

## Typography

| Family | Role |
|---|---|
| **Outfit** | Headlines, display text, hero titles, numbers |
| **Inter** | Body text, form labels, captions, button labels |

## Design Hierarchy & Rules

- **Backgrounds**: Flat warm cream `#FBF8F2` (no fabric texture overlays, no fake borders)
- **Cards**: Pure white `#FFFFFF` with smooth rounded corners (`border-radius: 20px - 24px`) and gentle drop-shadows
- **Navigation**:
  - Header: Profile avatar (left) + "Smriti Sathi" (center) + Mic button (right)
  - Bottom Tab Bar: Deep dark navy bar (`#0B131F`) with coral-red active tab pill (`#FF5F56`)
- **Buttons**:
  - Primary CTA: Red pill `#9E2224` (`border-radius: 9999px` or `14px`)
  - Secondary/Outlined: Light gray `#ECECF0` or thin outline `#E5E7EB`
